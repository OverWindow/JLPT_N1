# 일본어 단어장 1.3.0

사진 속 단어를 30개씩 공부하는 Android/iOS Flutter 앱입니다. 서버·계정·광고 없이 내장 JSON과 휴대폰의 학습 기록으로 오프라인에서 동작합니다.

## 설치와 실행

Android 설치 파일: `releases/jlpt-1.3.0.apk` (ARM64, ARMv7, x86_64 포함).
휴대폰으로 파일을 옮겨 열고 설치합니다. 기존 앱은 삭제하지 않고 덮어 설치할 수 있습니다. 앱 식별자 `com.example.jlpt`와 기존 Flutter 개발 서명을 유지했습니다.

개발 환경은 Flutter 3.47.1 / Dart 3.13.1입니다. 최초 의존성 설치에는 인터넷이 필요합니다.

```sh
flutter pub get
flutter run
```

기기가 여러 대면 `flutter run -d <기기ID>`를 사용합니다. iOS는 macOS/Xcode에서 Team과 서명을 설정해야 합니다. Windows에서는 iOS 빌드·설치 검증을 할 수 없습니다.

## 공부 방법

1. 홈에서 세트를 선택하면 세트의 전체 단어를 무작위로 섞습니다. 한 회차에 중복·누락이 없습니다.
2. 한자(없으면 가나)를 보고 발음과 뜻을 떠올립니다.
3. 왼쪽 **모름** / 오른쪽 **알고 있음** 중 하나를 누르면 응답을 저장하고 발음·한국어 뜻을 공개합니다. 정답 아래에는 제목 없이 작은 글씨로 예문 한 개가 나오며, 예문의 한자 위에 후리가나와 아래에 한국어 해석을 표시합니다. 정답을 본 뒤 같은 버튼으로 판단을 바꿀 수 있습니다.
4. **다음 단어**로 이동합니다. 이동하면 정답은 다시 숨깁니다.
5. 마지막 단어 뒤 **이번 학습 종료**와 현재 알고 있는 개수가 나옵니다. **다시 학습하기**는 순서만 새로 섞고 기록은 유지합니다.

문제 한자는 세로 휴대폰 화면 중앙 쪽의 별도 영역에 고정합니다. 정답 공개 여부와 관계없이 문제와 응답 버튼 위치가 같습니다. 정답·예문 공간을 미리 확보하고 내용 크기를 화면에 맞춰 조절하므로 퀴즈 화면은 스크롤되지 않습니다. 다음 단어 버튼은 하단 너비를 채우고 위치가 고정됩니다. 알고 있음·모름은 정답만 공개하며, 이후 다음 단어 버튼을 눌러야 이동합니다.

홈 진행바는 각 단어의 **마지막 응답**을 반영합니다. 모두 알고 있으면 **학습 완료**, 이후 모름으로 바꾸면 완료 표시도 해제됩니다. 앱을 종료하고 다시 실행해도 기록을 복원합니다. 앱 삭제나 앱 데이터 삭제 시 기록은 지워집니다.

`ProgressStore`는 `SharedPreferencesAsync`에 알고 있는 단어 키 집합을 저장합니다. 키는 공백을 제거한 표기·발음 조합으로, 순서·그룹 번호·뜻 변경의 영향을 받지 않습니다. 저장 성공 후 진행도를 반영하고 저장 중 버튼과 뒤로가기를 막습니다. 실패하면 재시도 버튼이 나타납니다.

## 단어와 아이콘

새 사진 10장(2026-10-11)의 양쪽 단어·표현 331개 중 중복 23개를 병합하고 **308개 추가**, 총 **1,130개·38세트**입니다. 기존 822개 순서와 기록 키를 유지하고 28번 세트의 빈 18자리부터 채웠으며, 마지막 세트는 20개입니다. 기존 28번 세트를 모두 알고 있었어도 새 항목 추가 후에는 12/30으로 표시됩니다.

앱은 `assets/words/words.json`만 읽습니다. 새 단어를 JSON 배열 끝에 추가하고 다시 빌드하면 그룹은 자동으로 생성됩니다.

```json
{"kanji":"学校","hiragana":"がっこう","korean":"학교"}
```

가나뿐인 단어는 `kanji: null`입니다. 원문 가타카나는 `hiragana` 필드에 그대로 보존합니다. 사진과 전사 TSV는 앱에 포함하지 않습니다. 사진별 전사 개수·병합 이력·사전 근거는 `data/README.md`, `data/import-v1.1.json`, `data/import-v1.3.json`에 있습니다.

아이콘 원본은 `assets/icon/app-icon.svg`입니다. `python tools/generate_icons.py`로 Android 일반·적응형 및 iOS 전체 크기를 생성합니다. 짙은 초록 배경과 아이보리 책·日 도형으로 구성했으며 폰트에 의존하지 않습니다.

## 검증

Flutter 명령은 동시에 실행하지 않고 순서대로 실행합니다.

```sh
flutter analyze
flutter test
flutter test integration_test/app_test.dart -d emulator-5554
flutter build apk
```

단위·화면 테스트는 데이터 대조, 랜덤 순서, 다음/재학습, 선택 변경, 저장·복원·실패 재시도, 완료 표시 해제, 작은 화면과 큰 글씨를 검사합니다. Android 통합 테스트는 실제 SharedPreferences 저장과 전체 앱 재생성 후 복원, 첫 세트 30개, 기존 28번 세트의 12/30 기록 보존과 확장된 30개, 마지막 세트 20개를 검사합니다.

최종 실행 결과 및 설치 파일 검증은 `verification/v1.3.0/results.json`에 기록합니다. 이전 버전 검증 자료와 APK는 별도로 유지합니다. 실물 휴대폰과 iOS 빌드는 이 Windows 환경에서 검증하지 않았습니다.

## 예문 데이터

전체 1,130개 단어에 단어 뜻과 용법을 보여 주는 짧은 창작 예문을 한 개씩 넣었습니다. 교재 예문의 전사가 아닙니다. 후리가나는 한자 표기 위에 단어 단위로 표시하며 한국어 문장 해석도 함께 제공합니다. 별도 패키지나 네트워크 호출은 사용하지 않습니다.

`data/examples/*.tsv`에서 `[漢字|かんじ]`로 후리가나를 작성하며, `{w}`는 원래 단어의 표기·발음으로 확장됩니다. `python data/build_examples.py`로 앱 JSON의 `example.segments`와 `example.korean`을 생성합니다. `python data/build_words.py`도 마지막에 예문을 함께 재생성합니다. 새 단어를 추가할 때는 예문도 작성합니다.

단위·화면 테스트 34개에서 예문 전체의 필수 값·후리가나 누락·원본 매핑, 저장 식별자 유지, 두 응답 버튼의 공개, 3개 화면 크기의 문제 좌표 고정, 큰 글씨·정답과 예문의 화면 내 표시·응답 버튼 위치 고정을 검증합니다.
