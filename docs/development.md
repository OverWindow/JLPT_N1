# 일본어 단어장 1.7.0

사진 속 단어를 30개씩 공부하는 Android/iOS Flutter 앱입니다. 서버·계정·광고 없이 내장 JSON과 휴대폰의 학습 기록으로 오프라인에서 동작합니다.

## 설치와 실행

Android 설치 파일: `releases/jlpt-1.7.0.apk` (ARM64, ARMv7, x86_64 포함).
휴대폰으로 파일을 옮겨 열고 설치합니다. 기존 앱은 삭제하지 않고 덮어 설치할 수 있습니다. 앱 식별자 `com.example.jlpt`와 기존 Flutter 개발 서명을 유지했습니다.

개발 환경은 Flutter 3.47.1 / Dart 3.13.1입니다. 최초 의존성 설치에는 인터넷이 필요합니다.

```sh
flutter pub get
flutter run
```

기기가 여러 대면 `flutter run -d <기기ID>`를 사용합니다. iOS는 macOS/Xcode에서 Team과 서명을 설정해야 합니다. Windows에서는 iOS 빌드·설치 검증을 할 수 없습니다.

## 공부 방법

첫 화면에서 **N1 단어 / N1 문법 / 조수사 / 부사 특집**를 선택합니다. N1의 기존 단어·기록은 그대로 유지합니다. 아래 30개 그룹 설명은 N1에 해당합니다.

1. 홈에서 세트를 선택하면 세트의 전체 단어를 무작위로 섞습니다. 한 회차에 중복·누락이 없습니다.
2. 한자(없으면 가나)를 보고 발음과 뜻을 떠올립니다.
3. 왼쪽 **모름** / 오른쪽 **알고 있음** 중 하나를 누르면 응답을 저장하고 발음·한국어 뜻을 공개합니다. 정답 아래에는 제목 없이 작은 글씨로 예문 한 개가 나오며, 예문의 한자 위에 후리가나와 아래에 한국어 해석을 표시합니다. 정답을 본 뒤 같은 버튼으로 판단을 바꿀 수 있습니다.
4. **다음 단어**로 이동합니다. 이동하면 정답은 다시 숨깁니다.
5. 마지막 단어 뒤 **이번 학습 종료**와 현재 알고 있는 개수가 나옵니다. **다시 학습하기**는 순서만 새로 섞고 기록은 유지합니다.

문제 한자는 세로 휴대폰 화면 중앙 쪽의 별도 영역에 고정합니다. 정답 공개 여부와 관계없이 문제와 응답 버튼 위치가 같습니다. 정답·예문 공간을 미리 확보하고 내용 크기를 화면에 맞춰 조절하므로 단어·조수사·부사 퀴즈 화면은 스크롤되지 않습니다. 문법 퀴즈는 정답 영역만 스크롤합니다. 다음 단어 버튼은 하단 너비를 채우고 위치가 고정됩니다. 알고 있음·모름은 정답만 공개하며, 이후 다음 단어 버튼을 눌러야 이동합니다.

홈 진행바는 각 단어의 **마지막 응답**을 반영합니다. 모두 알고 있으면 **학습 완료**, 이후 모름으로 바꾸면 완료 표시도 해제됩니다. 앱을 종료하고 다시 실행해도 기록을 복원합니다. 앱 삭제나 앱 데이터 삭제 시 기록은 지워집니다.

`ProgressStore`는 `SharedPreferencesAsync`에 알고 있는 단어 키 집합을 저장합니다. 키는 공백을 제거한 표기·발음 조합으로, 순서·그룹 번호·뜻 변경의 영향을 받지 않습니다. 저장 성공 후 진행도를 반영하고 저장 중 버튼과 뒤로가기를 막습니다. 실패하면 재시도 버튼이 나타납니다.

## 단어와 아이콘

새 사진 14장(2026-11-08)의 단어·표현 240개 중 중복 28개를 병합하고 **212개 추가**, 총 **1,342개·45세트**입니다. 기존 1,130개 전체 데이터와 기록 키를 유지하고 38번 세트의 빈 10자리부터 채웠으며, 마지막 세트는 22개입니다. 기존 38번 세트를 모두 알고 있었어도 새 항목 추가 후에는 20/30으로 표시됩니다.

N1 단어 화면은 `assets/words/words.json`을 읽습니다. 새 단어를 JSON 배열 끝에 추가하고 다시 빌드하면 그룹은 자동으로 생성됩니다.

```json
{"kanji":"学校","hiragana":"がっこう","korean":"학교"}
```

가나뿐인 단어는 `kanji: null`입니다. 원문 가타카나는 `hiragana` 필드에 그대로 보존합니다. 사진과 전사 TSV는 앱에 포함하지 않습니다. 사진별 전사 개수·병합 이력·사전 근거는 `data/README.md`, `data/import-v1.1.json`, `data/import-v1.3.json`, `data/import-v1.6.json`에 있습니다.

아이콘 원본은 `assets/icon/app-icon.svg`입니다. `python tools/generate_icons.py`로 Android 일반·적응형 및 iOS 전체 크기를 생성합니다. 짙은 초록 배경과 아이보리 책·日 도형으로 구성했으며 폰트에 의존하지 않습니다.

## 검증

Flutter 명령은 동시에 실행하지 않고 순서대로 실행합니다.

```sh
flutter analyze
flutter test
flutter test integration_test -d emulator-5554
flutter build apk
```

단위·화면 테스트는 데이터 대조, 랜덤 순서, 다음/재학습, 선택 변경, 저장·복원·실패 재시도, 완료 표시 해제, 작은 화면과 큰 글씨를 검사합니다. Android 통합 테스트는 실제 SharedPreferences 저장과 전체 앱 재생성 후 복원, 첫 세트 30개, 기존 38번 세트의 20/30 기록 보존과 확장된 30개, 마지막 세트 22개를 검사합니다.

최종 실행 결과 및 설치 파일 검증은 로컬 `verification/v1.7.0/results.json`에 기록합니다. `verification/`은 Git에서 제외합니다. 이전 버전 검증 자료와 APK는 별도로 유지합니다. 실물 휴대폰과 iOS 빌드는 이 Windows 환경에서 검증하지 않았습니다.

## 예문 데이터

전체 1,342개 단어에 단어 뜻과 용법을 보여 주는 짧은 창작 예문을 한 개씩 넣었습니다. 교재 예문의 전사가 아닙니다. 후리가나는 한자 표기 위에 단어 단위로 표시하며 한국어 문장 해석도 함께 제공합니다. 별도 패키지나 네트워크 호출은 사용하지 않습니다.

`data/examples/*.tsv`에서 `[漢字|かんじ]`로 후리가나를 작성하며, `{w}`는 원래 단어의 표기·발음으로 확장됩니다. `python data/build_examples.py`로 앱 JSON의 `example.segments`와 `example.korean`을 생성합니다. `python data/build_words.py`도 마지막에 예문을 함께 재생성합니다. 새 단어를 추가할 때는 예문도 작성합니다.

단위·화면 테스트 61개에서 N1·문법·조수사·부사 특집 데이터·기록·동작과 3개 화면 크기의 문제·응답 버튼 위치 고정을 검증합니다.

## 조수사 학습

- 동물 3세트, 날짜 2세트, 기간 3세트, 사람 1세트, 물건 5세트, 시간 3세트로 총 17세트·270표현입니다. 각 세트는 ‘몇’을 묻는 문제도 포함합니다. 달력의 날짜는 1~31일과 何日까지 32문제를 한 세트로 제공합니다.
- `assets/counters/counters.json`만 추가로 읽고, 기존 N1 JSON은 바꾸지 않습니다. `python data/build_counters.py`로 읽기 표와 창작 예문에서 재생성합니다. 범위·대체 읽기·출처는 `data/counters/README.md`에 있습니다.
- 조수사는 표기와 읽기의 변화에 영향을 받지 않는 고정 ID를 사용하며 `known_counter_keys_v1`에 따로 저장합니다. N1은 기존 `known_word_keys_v1`과 표기·발음 기반 키를 그대로 사용합니다.
- 기존 퀴즈와 예문 위젯을 공유합니다. 조수사에서는 상단에 분류·세트 이름을, 버튼에는 ‘다음 문제’와 ‘조수사 목록으로’를 표시합니다. 정답 공개·저장 실패 재시도·판단 변경·랜덤 재학습 동작은 동일합니다.
- Android 통합 테스트에서 첫 화면의 진입 경로, 날짜 전체 32문제와 기간의 一日 읽기 구분, 조수사 기록 복원과 N1 저장 값 불변을 확인합니다. APK 검증 도구는 1.5.0 APK와 서명·기존 N1 1,130개 및 조수사·부사 특집 전체 JSON을 대조합니다.

## 부사 특집 학습

- 1.5.0+11: 새 사진 11장의 부사 64개와 접속 표현 35개, 총 99개·8세트이다. 부사는 30·30·4개, 접속 표현은 교재의 5개 분류별로 나눈다.
- `python data/build_adverbs.py`로 `data/adverbs/entries.tsv`의 고정 ID·전사·창작 예문을 `assets/adverbs/adverbs.json`과 사진별 감사 파일로 재생성한다. `[漢字|かんじ]` 구문을 기존 예문 segments로 변환하며 원본 사진은 앱에 포함하지 않는다.
- `AdverbLoader`는 필수 값·ID 중복·읽기·예문을 검사한다. `AdverbScreen`은 분류별 세트와 진행도를 표시하며 기존 `QuizScreen`을 공유한다. `WordApp`과 `EntryScreen`은 선택적 `adverbProgressStore` 주입을 지원한다.
- `known_adverb_keys_v1`은 기존 N1·조수사 저장 키와 독립적이다. 동일 표기의 다른 용법(あるいは 등)도 별도 ID를 갖는다. 1.5 도입 시 N1 1,130개와 조수사 270개는 바이트 단위로 보존했다. 1.6에서는 N1 끝에 새 단어를 추가하며 이전 항목 전체를 유지한다.
- 부정 표현의 `～ない`를 유지한다. 가나 표제어는 문제 자체에 읽기가 보이므로 기존 퀴즈와 같이 중복 읽기 줄을 표시하지 않는다. 뜻과 예문은 응답 후 공개한다.
- Android 통합 테스트는 특집 99개 전체의 무중복 출제·두 버튼 정답 공개·고정 위치·완료·복원·완료 해제와 기존 두 저장 키 불변을 검사한다. APK 검증 도구는 1.5 APK와 기존 N1 항목·조수사·부사 JSON 및 서명을 대조한다.

## 1.7.0 N1 문법

- 명사 87개, 동사 76개, 명사·동사 32개, 여러 품사 59개, 총 254개를 10개 세트로 제공합니다. 사진 68장의 표제와 번호를 보존하며 N2 복습 문형도 포함합니다.
- `python data/build_grammar.py`는 네 TSV와 사진 검토 목록에서 `assets/grammar/grammar.json` 및 `data/grammar/import-v1.7.json`을 만듭니다. 한국어 뜻, 접속 설명, 창작 예문의 후리가나와 해석을 필수로 검사합니다.
- `GrammarLoader`는 고정 ID 중복, 빈 접속 설명·예문, 읽기·후리가나 오류를 거부합니다. 기존 `JapaneseWord`의 선택적 `connection`을 사용하므로 기존 데이터 형식을 유지합니다.
- `known_grammar_keys_v1`에 문법만 저장합니다. ‘아직 모르는 문형만 복습’은 아직 공부하지 않았거나 마지막 응답이 모름인 문형을 세트별로 선택합니다. 복습할 항목이 없는 세트는 비활성화됩니다.
- 문제와 응답 버튼은 고정하고 뜻·접속·예문 영역만 스크롤합니다. 다음 문형으로 이동할 때 스크롤과 정답 공개 상태를 초기화합니다.
- `test/grammar_test.dart`는 254개 사진 표제 일치, 세트·ID·필수 데이터, 잘못된 데이터 거부, 전체 문형의 390×844 / 320×568 / 640×320 화면과 글씨 2배, 복습 필터·오류 재시도를 검사합니다. `integration_test/grammar_test.dart`는 실제 Android에서 첫 세트 29개와 기록 복원·기존 세 저장 키의 불변을 검사합니다.
- `tools/verify_apk.py`는 1.6.0 APK를 기준으로 기존 세 데이터 전체, 패키지·서명·ABI·인터넷 권한, 새 문법 254개를 대조합니다.
