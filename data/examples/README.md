# 예문 원본

1,130개 단어별 학습용 창작 예문입니다. 교재 예문을 전사한 자료가 아닙니다.
TSV: 단어 번호, 후리가나 마크업이 포함된 일본어 문장, 한국어 해석.
`{w}`는 해당 단어의 표기·발음으로 확장합니다. `[漢字|かんじ]`는 한자와 후리가나입니다.
`python data/build_examples.py`로 표기·발음 조합에 연결한 `example`을 words.json에 넣습니다.
단어 의미에 맞춘 짧은 문장을 사용하며, 앱은 런타임 생성이나 네트워크를 사용하지 않습니다.

1.3에서 823~1130번의 창작 예문 308개를 추가했습니다. 1~822번 예문은 그대로 유지합니다.
긴 표현도 실제 문장 안에서 사용하며, 자연스러운 용법을 위해 ありふれる는 예문에서 ありふれている로 활용했습니다.
