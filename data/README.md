## 1.2 예문 추가

- `examples/*.tsv`는 각 단어의 뜻과 용법에 맞춰 작성한 짧은 창작 예문과 한국어 해석이다. 사진의 예문을 전사한 데이터가 아니다.

- `build_examples.py`는 822개 전부의 커버리지, 중복 번호, 비어 있는 해석, 후리가나 없는 한자와 남은 마크업을 검사한다. 단위 테스트는 원문 TSV와 앱 JSON의 일치, 중복 예문 및 기존 기록 키의 유지도 확인한다.
- 예문과 뜻은 앱 JSON에 모두 포함된다. 앱 실행 중 자동 생성·번역·외부 조회는 하지 않는다.
