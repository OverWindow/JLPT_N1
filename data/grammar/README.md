# N1 문법 254개

`image/`의 서로 다른 문법 사진 68장에서 확인한 번호별 문형 254개를 모두 수록합니다. 동일 사진의 복사본 30개는 중복 출제하지 않습니다. 슬래시로 병기된 변형은 교재의 한 번호를 그대로 한 학습 항목으로 취급합니다. 교재의 N1 필수 문법 단원에는 N2 복습 문형도 포함되어 있습니다.

| 분류 | 문형 | 세트별 개수 |
| --- | ---: | --- |
| 명사 | 87 | 29 · 29 · 29 |
| 동사 | 76 | 26 · 25 · 25 |
| 명사·동사 | 32 | 16 · 16 |
| 여러 품사 | 59 | 30 · 29 |

표제·번호는 `photo-review-2026-11-08.json`의 검토 목록을 기준으로 합니다. 사진 21장에 일부 잘림이 있으므로 교재 본문 전체를 전사했다고 간주하지 않습니다. 한국어 뜻과 접속 설명은 학습용으로 정리했으며, 각 항목의 짧은 예문과 번역은 새로 작성했습니다. 모든 예문의 한자에 후리가나가 있습니다. 복수 의미·변형을 가진 문형의 예문 한 개는 대표 용법을 보여 줍니다.

`noun.tsv`, `verb.tsv`, `mixed.tsv`, `multi.tsv`에는 `number`, `korean`, `connection`, `example`, `example_korean` 필드를 작성합니다. 예문의 `[漢字|かんじ]`를 후리가나로 변환합니다. 접속 설명에서 ‘ます형에서 ます 제외’는 어간을 뜻하며, `する → せず / せざる / せん` 등의 예외를 별도 표시했습니다. `～てもともとだ`는 `て + もともとだ`이며 `ても + もともとだ`로 붙이지 않습니다.

```sh
python data/build_grammar.py
```

생성기는 번호 전체 범위, 사진 표제와 일치 여부, 고정 ID, 빈 필드, 한자의 후리가나 누락을 검사하고 `assets/grammar/grammar.json`과 `import-v1.7.json`을 생성합니다. 감사 파일은 254개 항목 각각을 원본 사진에 연결하고 부분 사진 여부와 추론한 번호를 보존합니다. 원래 사진 검토 파일은 당시의 검토 기록으로 유지합니다.

학습 ID는 `grammar.<noun|verb|mixed|multi>.<001부터 시작하는 번호>`이고, 저장 키는 `known_grammar_keys_v1`입니다. 순서를 바꾸거나 뜻·예문을 수정해도 ID를 바꾸지 않습니다. 단어·조수사·부사 데이터와 기록은 독립적입니다. ‘아직 모르는 문형만 복습’에는 미학습 및 마지막 응답이 모름인 문형이 포함됩니다.

접속 예외와 비슷한 표현의 차이는 다음 설명도 대조했습니다: [Bunpro의 んがため](https://bunpro.jp/ja/grammar_points/んがため-に), [Benri의 んばかり](https://www.benri.jp/jlpt/n1/grammar/n-bakari-no), [국제교류기금의 역접 표현 설명](https://www.jpf.go.jp/j/project/japanese/teach/tsushin/grammar/201703.html), [일본어 교사의 もかまわず 설명](https://nihongokyoshi-net.com/2019/06/04/jlptn2-grammar-kamawazu/).
