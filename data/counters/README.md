# 조수사 데이터 · 1.4

앱은 `assets/counters/counters.json`을 오프라인으로 읽습니다. `python data/build_counters.py`로 읽기 표와 직접 작성한 예문 템플릿에서 재생성합니다. N1의 단어 JSON과 기록은 수정하지 않습니다.

## 범위

## 표기·읽기와 출처

- 기본 읽기, 날짜의 14·19·20·24·29일, 월의 4·7·9월, 시각과 분, 주간은 [국제교류기금의 수사·조수사 자료](https://www.jpf.go.jp/j/project/japanese/survey/area/country/syllabus/pdf/sy_honyaku_4china.pdf)와 대조했습니다.
- 사람·물건·동물·기간의 읽기와 용법은 [텍사스대학교 JOSHU 조수사 학습 자료](https://laits.utexas.edu/japanese/joshu/counters/counters_category.php)를 함께 확인했습니다. 원문 예문이나 번역을 복사하지 않았습니다.
- 一日은 달력에서 ついたち, 기간에서 いちにち입니다. 표기가 같아도 ID는 calendar.day.1 / duration.day.1로 구분합니다. 한국어 뜻과 상단 세트 이름도 날짜/기간을 구분합니다.
- つ는 十를 とお로 읽으며 ‘十つ’로 쓰지 않습니다. 질문은 幾つ(いくつ)입니다. 개월은 ヶ月 표기를 사용하며 ‘かげつ’로 읽습니다.
- 발음 변화가 있는 조수사의 十·二十·三十는 일상적인 じゅっ 계열을 대표 읽기로, じっ 계열을 대체 읽기로 제공합니다. [東京書籍의 十 읽기 설명](https://faq.tokyo-shoseki.co.jp/fa/customer/web/knowledge8248.html)은 두 형태가 인정됨을 설명합니다.
- 羽는 학습용 대표 읽기를 わ 계열로 통일합니다. 三羽에는 さんば, 十羽에는 じっぱ·じゅっぱ, 百羽에는 ひゃっぱ도 표시합니다. 二十羽·三十羽도 같은 십 단위 변화를 적용합니다. [小学館 『数え方の辞典』 칼럼](https://japanknowledge.com/articles/kze/column_kaz_13.html)을 대조했습니다.
- 四分은 よんぷん을 대표로, よんふん을 대체로 표시합니다. 八分의 はちふん, 八ヶ月의 はちかげつ 등은 [국제교류기금 기간 자료](https://www.kyozai.jpf.go.jp/kyozai/material/BTS00009/ja/render.do)와 기본 읽기 자료를 대조했습니다. 대표형은 はっぷん / はっかげつ입니다.
- 七人의 しちにん, 七枚의 しちまい, 八個의 はちこ를 대체형으로 제공합니다. 九人은 きゅうにん을 대표로, [JLect의 九人 항목](https://www.jlect.com/entry/790/kunin/)에 있는 くにん을 대체형으로 제공합니다. 모든 역사적·방언적 변형을 나열한 목록은 아닙니다.
- 20·30과 시각의 10~23, 분의 15~59는 검증한 기초 수사와 조수사의 결합으로 생성합니다. 百匹・百本・百個・百ヶ月의 촉음과 百頭・百冊・百週間의 비촉음을 별도로 지정합니다. 달력 날짜의 예외를 일반 수사 결합으로 덮어쓰지 않습니다.
- 百ヶ月의 ひゃっかげつ는 [Tofugu의 개월 설명](https://www.tofugu.com/japanese/japanese-counter-tsuki-gatsu-getsu/), 零分의 れいふん은 [90 Day Japanese의 시각 읽기 표](https://90dayjapanese.com/telling-time-in-japanese/)로 추가 대조했습니다. 영(0)의 대표 읽기는 れい로 통일했습니다.

## 예문과 기록

예문은 세는 대상과 맥락을 분명히 한 직접 작성 문장입니다. 각 숫자를 넣은 문장에는 대표 읽기의 후리가나와 해당 숫자를 반영한 한국어 해석이 들어갑니다. ‘몇’ 항목은 별도의 의문문을 사용합니다. 읽기의 대체형은 정답 읽기 줄에 표시하며, 예문에는 대표형 한 개만 사용합니다.

JSON의 고정 ID는 `세트 ID.숫자`이며 질문은 `.question`입니다. 읽기나 해석을 보완해도 ID를 바꾸지 않습니다. 조수사의 알고 있음 집합은 `known_counter_keys_v1`에, N1은 기존 `known_word_keys_v1`에 저장합니다.

자동 검사는 숫자 범위·중복 ID·필수 값·가나 읽기·한자 숫자·후리가나 누락·예문 내 표제어와 대표 읽기의 일치를 확인합니다. 주요 특수 읽기는 별도 회귀 테스트로 고정합니다. 언어 정확성은 위 자료와 수동 검토를 함께 사용하며, 자동 검사가 의미의 자연스러움까지 보증하지는 않습니다.
