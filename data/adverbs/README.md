## 판독 및 용법 결정

- 파일명 순서와 페이지 순서가 다르므로 책 페이지 순서를 사용했다. 각 페이지의 주요 표만 전사하고, 도입 문제·확인 문제·설명·옆 페이지 조각은 제외했다. 사진의 표제어와 읽기는 직접 대조했으며 판독 불명으로 남긴 항목은 없다.
- 부사 64개는 30·30·4개로 분할한다. 접속 표현은 교재의 순접 7, 병렬·선택 4, 역접 7, 전환·환언 6, 첨가·보충 11개 분류를 유지한다. 분류명은 교재의 학습 분류이며 모든 단어가 그 품사로만 쓰인다는 뜻은 아니다.
- `あるいは`는 130쪽의 추측(어쩌면)과 137쪽의 선택(또는)을 각각 별도 ID로 보존한다.
- `一向に～ない`, `必ずしも～ない`, `まず～ない` 등의 부정 호응을 삭제하지 않는다. `～`는 빈자리를 나타내는 기호이며 읽기에서도 유지한다. `ちっとも`, `何も`, `なんら`는 표제어에 기호를 덧붙이지 않고, 예문에서 부정 용법을 보여 준다.
- `何も`는 134쪽의 ‘굳이’ 용법, `もっとも`는 140쪽의 단서·보충 용법이다. ‘아무것도’, ‘가장’으로 잘못 바꾸지 않았다.
- `その上`, `見る見る` 등은 원문 한자 표기를, `あらかじめ`, `したがって`, `ときに` 등은 원문 가나 표기를 보존한다. 표제어 내부 공백과 물결 기호만 일관되게 정리했다.
- 예문은 교재 문장을 옮기지 않고 각 용법에 맞춰 짧게 작성했다. 접속 표현에는 관계를 이해할 수 있는 짧은 앞뒤 문맥을 넣었다. `[漢字|かんじ]` 표기를 기존 후리가나 segments 구조로 변환한다. 한국어 예문 해석은 자연스러운 문장으로 번역하여 표제어의 직역과 달라질 수 있다.

특집 진행도는 `known_adverb_keys_v1`에 저장한다. 기존 N1·조수사 저장 키와 독립적이며, JSON과 예문은 모두 앱에 내장되어 오프라인으로 동작한다.
